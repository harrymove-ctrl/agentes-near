# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-14

## Decision

We keep short ADRs in `docs/adr/`, in English, one decision per file: context, decision, consequences.

## Consequences

- A change of direction is a new ADR that supersedes the old one, never an edit that hides history.
- Code comments point at ADRs instead of repeating the reasoning.
