# Avatar

Pessoas são círculos em `surface-sunken`; agentes são quadrados `agent` com o canto vivo inferior esquerdo. Mostra iniciais (1–2 letras) ou foto. Presença: ponto `ink` (`success`) para pessoa online, `agent` para agente disponível. `ac-avatar--running` desenha um anel enquanto o agente executa. Tamanhos: 24, 36 (padrão) e 56px. Sempre com nome acessível (`aria-label`) quando não houver nome visível ao lado.
